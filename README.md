# Mini Arcade

Mini Arcade és una màquina de jocs per consola feta amb Python. Et permet jugar a dos jocs des d'un menú principal: Pedra, Paper, Tisora una versió expandida contra el robot i Endevinar el Número.

En Pedra, Paper, Tisora pots triar entre jugar al primer que arribi a 3 victòries o al millor de 5 rondes. A Endevinar el Número, el programa pensa un número entre 1 i 100 i et dona pistes fins que l'encertes, comptant els intents.

## Com executar el projecte

1. Instal·la Python 3 al teu ordinador.
2. Descarrega o clona aquest repositori.
3. Obre una terminal a la carpeta del projecte.
4. Executa el programa amb:

```
python main.py
```

5. Tria una opció del menú: `1` per a Pedra, Paper, Tisora, `2` per a Endevinar el Número o `S` per sortir.
